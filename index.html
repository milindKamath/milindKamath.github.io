About

Comfortable with ambiguity, obsessed with data quality.

I'm a Senior Software Engineer in Data at Egen Solutions, where I've spent the last five years building and owning large-scale data platforms across Azure, GCP, and AWS — everything from streaming ingestion to Gold-layer analytics for healthcare and automotive enterprises.

I'm most productive when I'm given a hard, ambiguous problem and the autonomy to solve it end-to-end: architecting the pipeline, negotiating the data contracts, and being the one accountable when it runs at 3am. Medallion architecture, CDC, and SCD Type 2 aren't buzzwords to me — they're how I think about keeping data trustworthy at scale.

Lately I've been leaning into AI-assisted engineering — using Claude Code and GitHub Copilot to accelerate pipeline development and refactor legacy SQL — plus deepening my ML pipeline chops through Vertex AI and hands-on LLM/RAG work.
